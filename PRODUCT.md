# TreeWriter — Product Context

## Register

**product** — A research writing tool (app UI). Design serves long-form academic workflows; prose surfaces use a distinct reading typography.

## Target users

Graduate students, lab researchers, and co-authors writing journal papers from structured outlines and drafts. They work for hours in one session, switching between navigation, section composition, unit editing, graph overview, and an AI terminal.

## Purpose

TreeWriter turns a folder-based paper model (papers → sections → units) into a focused writing environment with outline/draft dual panes, markdown editing, comments, export, and agent dispatch — without leaving the repo.

## Brand personality

**Calm · precise · scholarly** — trustworthy like a good reference manager, not flashy like a consumer app.

## Anti-references

- Generic SaaS purple gradients and card-in-card layouts
- Inter-only everything with gray muted body text on tinted backgrounds
- Dark-mode-by-default coding aesthetic in the writing surface
- Over-animated onboarding and modal-heavy flows

## Strategic principles

1. **Writing first** — chrome stays quiet; editor and reading surfaces get the best typography and contrast.
2. **Spatial consistency** — same sidebar / workspace / agent panel grammar on every screen.
3. **State clarity** — git sync, terminal, save status, and section progress are always legible.
4. **Density with breath** — compact nav, generous prose column (~42rem), clear pane headers.

## Accessibility

WCAG AA contrast minimum. Keyboard focus visible on all controls. `prefers-reduced-motion` respected. Atkinson Hyperlegible for UI chrome; serif stack for long-form reading.
