# Scientific writing framework — Levels 2–4 reference

Consult on demand when auditing section function, paragraph flow, or word-level polish. Level 1 (story arc) stays in `scientific-writing-framework-skill.md`.

## Level 2 — Section: function

| Section | Purpose | Structure | Target reader |
|---------|---------|-----------|---------------|
| **Title** | Describe what was *found* (not done) | Concise, keyword-rich, no acronyms/clichés | All |
| **Abstract** | Self-contained story | Hourglass / 7-block | Busy reader |
| **Introduction** | Elaborate "why?", set the scene | Funnel: general → specific | General reader |
| **Methods** | Enable exact repetition ("recipe") | Logical step sequence | Expert |
| **Results** | Present findings as evidence | Sequence tied to figures | Expert |
| **Discussion** | Interpret, compare to prior work | Claim → evidence → context | Expert |
| **Conclusions** | Answer "so what?" | Implications + limitations | Cross-disciplinary |
| **Supplementary** | Remove reproducibility barriers | Datasets, code, extended methods | Newcomer |

**Nature abstract — 7-block formula:** (1) intro any scientist grasps; (2) detailed background; (3) general problem; (4) **main result — "here we show/present"**; (5) vs prior knowledge; (6) general validation; (7) broader perspective (optional). ~190–250 words.

**Grant-proposal failure mode:** broad context → method → vague results. Lead with the result; test: *could a reader state the main finding from the abstract alone?*

**Introduction funnel:** field → why it matters → prior work → gap ("However, …") → aim → contribution ("Here, we …").

**Results:** each paragraph makes a scientific *statement* using the figure as evidence — not a caption replay. **Discussion:** open with interpreted main finding, not Results replay.

**Verb tense:** Introduction facts = present; prior work = past; Methods/Results = past; Discussion/Conclusions = present (outlook = future).

## Level 3 — Paragraph and sentence

**Paragraph:** one idea; topic/signposting first sentence; delete if removable without loss.

**Signposting leading sentences:** "Historically, …" / "Our approach …" / "These results suggest …" / "By contrast, …" / "Having established X, …"

**Theme–rheme:** end of sentence N → topic of N+1.

**Cut blank-post openers:** "It is important to note that…", bare "Moreover/Additionally/Furthermore".

## Level 4 — Word

For TreeWriter draft slop specifically, use **writing-deslop-basics**.

**Declutter:** end result → result; in order to → to; due to the fact that → because.

**Hype → measured:** proves → indicates; dramatic increase → increased by X%; paradigm shift → new approach.

**Dashes:** hyphen for compound modifiers; en-rule for ranges; em-rule for parenthetical breaks (sparingly).

## FINER — research question

**F**easible, **I**nteresting, **N**ovel, **E**thical, **R**elevant.

## Pre-submission checklist

**Story** — 4 sentences (background / however / here / so what); abstract hourglass with "here we show"; intro funnel; conclusions answer "so what?".

**Structure** — descriptive headings; Methods are a recipe; SI has no new conclusions; reproduction from text + SI + repo.

**Paragraph** — signposting first sentences; theme–rheme chain; parallel lists.

**Word** — no hype without specifics; notation and tenses consistent.
