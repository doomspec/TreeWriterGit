# Status Column

## Current implementation (2026)

The right column is the **Agent panel** (collapsible):

* AI Dispatch (top, scrollable)
* Terminal (bottom, flex-grow)

When collapsed, a narrow rail with icons remains for reopening.

## Original spec

Leave the right column blank.

The blank column was repurposed for agent + terminal tooling during the Overleaf-style layout refactor.
