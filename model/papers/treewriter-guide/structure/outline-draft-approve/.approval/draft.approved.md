Unit status flows **outline → drafted → approved**. Only **approved** units export by default.

For each paragraph: create a unit under a section, write the **outline** brief, write the **draft** prose (use `[@cite_key]` for citations), then click **Approve**. Approval copies the working draft to **`.approval/draft.approved.md`** inside the unit folder — that snapshot is what export uses.

Amber rows in the Sections tree mean unapproved `draft.md` changes somewhere beneath. Use **Approve all in children** in section view for bulk approval.

Each unit, section, and subsection also has **`temp-notes.md`** — a scratchpad that autosaves but is not exported and needs no approval.
