# Model Directory

The `model/` directory contains the document content and structure.

Content is organized as a hierarchy of nested folders and Markdown files. Every folder contains an `INDEX.md` file that serves as the entry point for that subtree.

Responsibilities of `INDEX.md`:

* Define the outline of the current section.
* Describe the purpose of the folder.
* Reference child sections and documents.
* Provide metadata and navigation information.

This structure turns the repository into a tree-shaped knowledge model where each node is represented by a folder and its associated `INDEX.md`.
